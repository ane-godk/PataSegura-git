# PataSegura

Plataforma web para ajudar tutores a encontrar serviços para pets.

## Instalação
1. Clone o repositório
2. Abra a pasta no VS Code

## Uso
Abra o arquivo `index.html` com o Live Server.

## Contribuição
Faça um fork, crie uma branch e envie um pull request.
